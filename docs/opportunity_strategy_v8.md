# A股快速轮动·发酵+资金持续+分歧转强+妖股基因短线策略 V8.0

> 本文档是「机会投资」功能的产品需求原文（用户提供，2026-09-04）。
> 后端实现见 `backend/opportunity_screener.py`，前端见 `frontend/static/js/page-opportunity.js`。
> 实现原则：**无法获取的数据必须标【数据缺失】，绝不编造**（见 第二十七节）。

## 一、核心交易目标

在A股快速轮动、热点持续时间短、资金博弈激烈的环境中，寻找：

「板块正在发酵 + 增量资金持续进入 + 个股分歧转强 + 龙头/中军带动 + 妖股基因 + 分时主动攻击 + 次日存在溢价预期」的短线机会。

核心原则：
1. 宁缺毋滥，最多推荐2只。
2. 没有达到三重准入门槛，不允许推荐。
3. 不因为PE高直接淘汰短线强势股。
4. 不因为振幅大直接淘汰妖股候选。
5. 不以MA5、MA10作为主要买卖依据。
6. 优先使用分钟级、资金级、板块级、情绪级数据。
7. 不追已经进入高潮末端的板块。
8. 不把「涨得最多」理解为「最值得买」。
9. 买的是「预期差+资金延续性」，不是已经完成的涨幅。
10. 如果全市场没有符合条件的股票，直接输出：【今日无符合条件标的，空仓优于强行交易】

## 二、市场情绪四档评级

- **A级 强势进攻**：涨停数明显增加、连板高度上升、20cm/30cm活跃、炸板率低、跌停少、高位股反馈好、龙头溢价明显、成交活跃、指数无系统风险。仓位70%~100%，可参与强趋势/龙头/分歧转强。
- **B级 结构性机会**：中性偏强、热点存在、梯队正常、龙头有溢价但轮动快、炸板率增加。仓位40%~70%，只做最强板块前排。
- **C级 弱势轮动**：热点持续时间短、龙头溢价下降、炸板增加、高位股亏钱效应、资金快速切换。仓位0%~30%，只做极强个股，禁止普通跟风。
- **D级 风险/退潮**：大面积跌停、高位股连续杀跌、龙头断板负反馈、炸板率极高、热点退潮、指数系统风险、主力大规模流出。原则上空仓；禁止追涨/打板/低吸弱势股/抄底杂毛/预测反转。

## 三、板块周期五阶段（0~100分）

1. **启动**（60~75）：首批涨停、龙头初显、板块资金流入、关注度增加但跟风少。可观察不盲追。
2. **发酵**（80~95，最高优先级）：涨停家数持续增加、龙头确认、中军同步、板块成交放大、主力连续流入、后排扩散、逻辑强化、相对大盘持续跑赢、龙头首分歧后迅速回流。
3. **高潮**（70~85）：大量涨停、龙头加速、后排补涨、一致性极强。禁止无脑追后排；龙头连续加速→等分歧；巨量高潮→降分。
4. **分歧**：良性分歧（85~95）＝结构未破+放量换手+资金回流+核心股企稳+龙头收复关键位+新涨停+主力回流→「分歧转强」；恶性分歧＝龙头跳水/核心跌停/资金流出/后排崩溃/炸板严重→进入退潮判断。
5. **退潮**（0~40）：龙头断板、高位杀跌、后排补跌、涨停减少、炸板增加、资金流出、相对走弱。禁止交易。

## 四、板块评分模型（100分）

板块资金流入20 / 涨停梯队15 / 龙头强度15 / 相对大盘强度10 / 成交额增长10 / 连续资金流入10 / 消息产业催化10 / 扩散程度5 / 分歧转强5。
优先「发酵最快+资金持续性最好+龙头最强+分歧后重新走强」，不是涨幅最高。

> 实现注：板块级资金流入与消息/产业催化暂无数据源，按【数据缺失】处理——板块总分按可用维度归一化并标注，不编造。

## 五、妖股基因100分

① 历史爆发能力10（历史连板/主升浪/妖股属性/市场记忆）② 市值弹性10（流通<300亿优先，<200亿加分，极小市值加弹性但加风险）③ 股价弹性8（<80元优先非硬性）④ 换手能力10（5%~20%优秀，观察上涨换手递增，避免无量上涨/巨量滞涨）⑤ 涨停/大阳基因12（历史涨停频率/首板质量/连板能力/次日反馈/趋势加速）⑥ 资金攻击性15（超大单/大单/主力净流入/净比/持续进入/主动买盘）⑦ 题材辨识度10（当前核心热点，避免冷门独立上涨）⑧ 龙头/核心地位10（龙头>中军>高辨识补涨>跟风）⑨ 股性5（易大涨/易涨停/高波动/资金抢筹）⑩ 分歧转强历史10（冲高回落→洗盘→资金回流→再突破）。
90~100极强 / 80~89强 / 70~79中等 / 60~69一般 / <60非优先候选。

## 六、基础硬筛选

当日涨幅+3%~+8%；换手5%~20%；量比≥2；成交额≥2亿；主力净流入>1000万；5日涨幅-5%~+20%；20日涨幅-15%~+30%；优先股价<80元；流通市值<300亿（<200亿加分）。
**PE 不作硬性条件（不得因PE高淘汰）；振幅不作硬性淘汰条件。**

## 七、资金持续性评分（100分）

当日主力净流入20 / 主力净比10 / 超大单净流入15 / 大单净流入10 / 近3日资金趋势15 / 近5日资金趋势10 / 30日资金趋势5 / 成交额增长5 / 换手与资金匹配5 / 板块资金共振5。
核心：「单日大额流入」≠持续性。T日进入→T+1→T+2→板块同步。当日大涨大流入但前几日持续流出→降分；连续流入+板块同步+龙头同步→加分。

## 八、分歧转强模型

「不是在最强的时候买，而是在分歧结束、再次转强的时候买。」
识别10项：①早盘快速拉升 ②出现抛压 ③股价回落 ④成交量放大 ⑤未破核心支撑 ⑥主力资金回流 ⑦分时站回均价线 ⑧突破分歧高点 ⑨板块同步回暖 ⑩龙头/中军同步走强。满足越多分越高。

## 九、分时攻击结构（1/5分钟级）

- **A级（最优）**：低开/平开→快速放量→突破早盘高点→回踩不破→量再放大→破前高。
- **B级（典型分歧转强）**：高开→快速回落→缩量企稳→均价线附近承接→主力回流→再突破。
- **C级（谨慎）**：高开→冲高→放巨量→回落→反复无法新高。
- **D级（禁止买入）**：高开→冲高→放量跳水→跌破均价线→主力持续流出。

## 十、分时强弱评分（100分）

主动攻击20 / 回踩承接15 / 突破质量15 / 成交量配合15 / 均价线强弱10 / 资金回流10 / 盘口主动买盘5 / 板块同步10。
≥85强攻击 / 75~84可参与 / 65~74观察 / <65放弃。

> 实现注：盘口五档主动买盘无数据源，该5分恒0并标【数据缺失】。

## 十一、涨停概率 zt_prob（模型估计，非真实概率）

变量：板块强度+龙头强度+分时攻击+资金流入+换手+量比+涨停历史+市值弹性+题材热度+市场情绪+分歧转强+连板梯队+封板质量。
≥0.65强攻击候选 / 0.55~0.64观察候选 / 0.45~0.54一般 / <0.45放弃。
数据不足时禁止人为编造——输出【数据缺失】并降置信度。

## 十二、次日溢价 premium_prob（模型估计）

变量：板块次日延续性+龙头次日溢价+封板质量+换手+资金持续性+分歧转强+市场情绪+板块梯队+个股辨识度+尾盘资金状态。
≥0.70优秀 / 0.60~0.69可交易 / 0.50~0.59谨慎 / <0.50放弃。

## 十三、三重准入门槛（全部满足才可推荐）

1. **板块门槛**：板块评分≥75 且非明显退潮；最佳发酵期/良性分歧期。
2. **个股门槛**：妖股基因≥70 且 资金持续性≥70 且 分时攻击≥75。
3. **概率门槛**：zt_prob≥0.55 且 premium_prob≥0.60 且 综合评分≥80。

只满足两道：禁止推荐。

## 十四、最终综合评分（100分）

板块周期20 / 资金持续性20 / 妖股基因20 / 分歧转强15 / 分时攻击10 / 市场情绪5 / zt_prob 5 / premium_prob 5。
≥90 ★★★★★核心候选 / 85~89 ★★★★强候选 / 80~84 ★★★可交易 / 75~79 ★★观察 / <75禁止推荐。

## 十五、尾盘买入系统

14:30~14:50 判断十项：板块强势/龙头不跳水/站均价线上方/主动买盘/破日内高点/缩量回踩/重新放量/主力续流/成交额放大/抢筹盘口。
最佳尾盘买点：14:30后 分歧→缩量→企稳→资金回流→突破日内高点。
禁止：14:30后 冲高→巨量→回落→跌破均价线→主力流出。

## 十六、动态止损

结构止损（破分歧低点）/ 资金止损（主力持续流出+板块走弱→降仓/止损）/ 板块止损（发酵/分歧→明显退潮→无论盈亏降仓）/ 时间止损（1~2日未按预期走强且板块未续发酵→主动退出）。禁止固定「跌5%就卖」。

## 十七、动态止盈

+5%~8%观察不主动卖；+10%~15%板块续发酵+资金续流+龙头续强→继续持有；+15%~25%出现放量滞涨+主力流出+板块高潮→分批止盈；长上影+巨量+主力大幅流出+板块退潮→主动退出。

## 十八、仓位管理

A级：单股20%~40%、最多2只、总仓70%~100%；B级：单股15%~30%、总仓40%~70%；C级：单股10%~20%、总仓0~30%；D级：0仓位。同一板块最多2只；禁止高度相关持仓堆叠。

## 十九、加仓规则

唯一允许：首买后 板块续发酵+个股破买价+资金续流+分时再放量+龙头续强+情绪未恶化。首次40%→确认突破+30%→再确认+30%。禁止亏损加仓。

## 二十、7条绝对排除规则

1. 板块明显退潮。2. 主力资金持续大幅流出（即使涨幅好）。3. 高开冲顶后放巨量跳水且破均价线。4. 单一消息暴涨但板块无资金共振。5. 纯后排跟风且龙头明显见顶。6. 预期收益/风险比<1.5:1。7. 市场情绪D级禁止主动追涨。

## 二十一、风险收益比

R/R = E_profit ÷ E_loss ≥1.5（优秀≥2.0），否则直接淘汰。

## 二十二、最终排名

综合评分→板块周期→资金持续性→分歧转强→妖股基因→分时攻击→premium_prob→zt_prob。
同分优先：发酵期板块 > 分歧转强 > 龙头/核心 > 资金连续流入 > 流通市值更小 > 股性更强 > 次日溢价概率更高。

## 二十三、最终只推荐最多2只

第一名核心进攻标的，第二名高赔率备选。只有1只达标只推1只；无达标输出【今日无符合条件标的，空仓优于强行交易】。

## 二十四/二十五、输出格式

先输出【市场状态】（情绪等级/板块周期/短线环境），再输出【今日最终候选】表：
| 排名 | 股票 | 代码 | 板块 | 综合分 | 妖股分 | 资金分 | 分歧转强 | 分时分 | zt_prob | premium_prob | 建议 |
每只股票输出完整档案：股票（价格/涨幅/换手/量比/成交额/流通市值/主力净流入/主力净比/5日/20日涨幅）、板块（评分/阶段/涨停数/资金/相对强度/是否发酵/龙头）、妖股基因、资金（当日/3日/5日/30日+评分）、分歧转强、分时、概率（zt_prob/premium_prob+依据）、交易计划（买入区间/尾盘条件/两档止损/两档止盈/失效条件/最大仓位）、结论（买入/观察/放弃+为什么现在买而不是明天买）。

## 二十六、核心交易逻辑

不找「今天涨得最多」，找「明天最可能继续获得资金关注」。
机会质量 = 板块发酵 × 资金持续 × 分歧转强 × 妖股基因 × 分时攻击 × 次日溢价 × 市场情绪。任一因子接近0 → 整体机会质量大幅下降。
优先级：板块 > 龙头/核心 > 资金 > 分歧转强 > 分时 > 个股技术形态 > PE。

## 二十七、禁止虚假精确数据

无法获取实时主力资金/实时板块资金/涨停数量/炸板率/分钟成交/盘口数据/zt_prob/premium_prob 时，**必须标记【数据缺失】并降低置信度**；不得自行编造。实时数据不足以完成三重准入 → 【暂不推荐】。

## 二十八、最终原则

宁可错过不做低质量交易；宁可空仓不追高潮末端；重点做「发酵期+分歧转强」；资金持续性优先于单日爆发；妖股基因找高弹性不是无脑追高；概率是估计不是确定；三重准入缺一不可；最终最多2只、没有足够优势就是0只。
